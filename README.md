# Linux Server Health Monitoring System

## Project Overview
A Bash-based Linux server monitoring tool that collects
system health information and generates reports.

## Features
- CPU usage monitoring
- RAM usage monitoring
- Disk space monitoring
- System uptime monitoring
- Resource usage alerts
- CSV monitoring history
- HTML health reports
- Automated monitoring using Cron

## Technologies
- Kali Linux
- Bash
- Linux commands
- Cron
- HTML

## Installation

Clone the repository:

git clone https://github.com/johnny255-v/linux-server-health-monitor.git

Enter the project:

cd linux-server-health-monitor

Give execution permission:

chmod +x scripts/health_monitor.sh

Run:

./scripts/health_monitor.sh

## Project Structure

- scripts/ - Monitoring scripts
- logs/ - Monitoring history
- reports/ - HTML reports

## Learning Outcomes

- Linux system administration
- Bash scripting
- Process and resource monitoring
- Cron automation
